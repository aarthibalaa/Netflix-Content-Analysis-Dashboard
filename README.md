# Netflix-Content-Analysis-Dashboard

This is an end-to-end data analytics project using Python and Power BI, where I explored and visualized Netflix title's content data. This interactive dashboard provides powerful insights into the platform’s content trends and performance.

The project explores Netflix's content to uncover trends related to movies, TV shows, ratings, directors, countries, and content additions over time.

## Project Objective

- Analyze Netflix's global content library.
- Compare Movies and TV Shows across different countries.
- Identify the most common content ratings.
- Discover top directors and countries contributing to Netflix content.
- Analyze content release trends and additions over the years.
- Build an interactive dashboard for effective storytelling and business insights.
